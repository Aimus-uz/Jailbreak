# GAMEPOINT: Jailbreak на узбекском и русском

Форк [edgegamers/Jailbreak](https://github.com/edgegamers/Jailbreak). Код автора не меняется:
переводы лежат в `tools/gp-lang/`, а при сборке скрипт `apply.py` подставляет их в исходники.

## Сборка
GitHub Actions → **GAMEPOINT build (uz + ru)** запускается при каждом коммите в `main` (или вручную: Run workflow).
Получаются два артефакта:
- `Jailbreak-uz`: все сообщения на узбекском;
- `Jailbreak-ru`: на русском.

На сервер ставится **один** из них: папку `Jailbreak` → `game/csgo/addons/counterstrikesharp/plugins/`.

## Что переведено
- все сообщения чата (командир, LR, особые дни, тишина, RTD, бунт, последний охранник);
- названия LR, особых дней, команд, наград RTD, меню (монетка, камень-ножницы-бумага, выбор оружия, маркер);
- ответы команды отсчёта.

Не переводятся: логи раунда для админов, названия оружия, названия цветов и форм маркера (их ждут команды).

## Изменено кроме перевода
- Особые дни **Прятки** и **Спидраннеры** у автора разрешены только донатерам EdgeGamers (`@ego/dssilver`).
  У нас — только админам (`@css/generic`).

## Обновление от автора
1. На GitHub: **Sync fork** → Update branch.
2. Если сборка упала на шаге *Apply texts* — автор поменял какой-то текст. В логе будет строка `NOT FOUND` с файлом:
   исправить `find` в `tools/gp-lang/entries_lang.py` или `entries_mod.py` и закоммитить.
